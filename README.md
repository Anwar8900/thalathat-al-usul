# ثلاثة الأصول — موقع تعريفي

موقع بسيط ومتجاوب يقدّم خلاصة كتاب **«ثلاثة الأصول وأدلتها»** للشيخ محمد التميمي رحمه الله،
في ثلاث صفحات، كلٌّ منها يبدأ بملخّص قصير ثم تفاصيل وشروح، إضافةً إلى صفحة اختبار.

## 🌐 الموقع المباشر

**https://anwar8900.github.io/thalathat-al-usul/**

> رابط GitHub: https://github.com/Anwar8900/thalathat-al-usul

## طريقة الفتح

اضغط نقراً مزدوجاً على **`index.html`** — يعمل مباشرة بدون إنترنت وبدون تثبيت أي برنامج.

## الأصول الثلاثة + الاختبار

1. **معرفة العبد ربه** — `asl-1.html`
2. **معرفة العبد دينه** — `asl-2.html`
3. **معرفة العبد نبيه ﷺ** — `asl-3.html`
4. **أختبر معلوماتك** — `quiz.html` (١٠ أسئلة، النتيجة من ١٠)

## الملفات

```
index.html            الصفحة الرئيسية (الصورة + الإطار الذهبي + أربع بطاقات)
asl-1.html            الأصل الأول: معرفة العبد ربه
asl-2.html            الأصل الثاني: معرفة العبد دينه
asl-3.html            الأصل الثالث: معرفة العبد نبيه ﷺ
quiz.html             صفحة الاختبار
assets/
  css/styles.css      ملف التنسيق الوحيد
  js/app.js           ملف السكربت العام
  js/quiz-data.js     بنك الأسئلة (١٠ أسئلة)
  js/quiz.js          منطق الاختبار
  img/logo.svg        الأيقونة (تُستخدم أيضاً كـ favicon وفي الترويسة)
  img/makka.jpg       صورة المسجد الحرام (الصفحة الرئيسية)
_tools/               أدوات استخراج نص الـ PDF (اختيارية، غير مطلوبة للموقع)
```

## المزايا

| الميزة | الوصف |
|---|---|
| **ألوان** | أخضر وأبيض مع لمسات ذهبية في العناوين |
| **خلفية صفحات الأصول** | خضراء داكنة دائماً لإبراز النص، في الوضعين النهاري والليلي |
| **عناوين ذهبية** | العنوان الرئيسي لكل صفحة بلون ذهبي مع ظل خفيف |
| **زر العودة للرئيسية** | أيقونة في أعلى كل صفحة من صفحات الأصول |
| **ليل / نهار** | زر في الترويسة، يحفظ اختيارك في المتصفح ويتبع النظام تلقائياً أول مرة |
| **انتقال سلس** | تلاشٍ عند الخروج، وظهور تدريجي للعناصر عند التمرير |
| **أيقونات الأصول** | ثلاث بطاقات، الضغط ينقل إلى الصفحة المطلوبة |
| **شريط التقدّم** | شريط علوي يوضّح نسبة القراءة |
| **العودة للأعلى** | زر يظهر بعد التمرير |
| **نسخ / مشاركة** | أزرار في الرئيسية والتذييل، مع تنبيه تأكيد |
| **الجوال** | قائمة مطوية، تخطيط متجاوب بلا تمدد أفقي |
| **اختبار** | ١٠ أسئلة بأربعة خيارات، تصحيح فوري، نتيجة من ١٠، ومراجعة للأخطاء |

## الاختبار

- عشرة أسئلة، لكلٍّ منها أربعةُ خيارات وواحدٌ صحيح.
- التصحيح يظهر فوراً بعد كل سؤال (أخضر صحيح / أحمر خطأ) مع سبب الإجابة.
- في النهاية تظهر **النتيجة من ١٠** داخل دائرة متحركة.
- عند **١٠ من ١٠**: رسالة تهنئة خضراء + زر إعادة الاختبار.
- عند **أقل من ذلك**: طلب مراجعة المادة + ثلاثة أزرار لمراجعة الأصول + قائمة بالأخطاء وإجاباتها الصحيحة + إعادة الاختبار.

**لتعديل الأسئلة:** افتح `assets/js/quiz-data.js` — كل سؤال كائن فيه `q` (نص السؤال)، `opts` (أربعة خيارات)، `ok` (رقم الخيار الصحيح)، `why` (سبب الإجابة).

## التخصيص السريع

- **الألوان**: عدّل المتغيّرات في أعلى `assets/css/styles.css`
  (`--green-700`, `--green-500`, `--gold` …) فيتغيّر كل شيء.
- **ألوان صفحات الأصول**: كتلة `body.page` داخل `styles.css`.
- **الأيقونة**: استبدل `assets/img/logo.svg` بشعارك (نفس الاسم).
- **الصورة الرئيسية**: استبدل `assets/img/makka.jpg`.
